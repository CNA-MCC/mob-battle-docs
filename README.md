# mob-battle
## ざっくりとした説明
このゲームでは、チームごとに**ゾンビのAIを書いて**、ゾンビ同士でバトルをします！

ゾンビは色々な行動ができます！

### アクション系
・剣で攻撃(1秒のクールダウンタイム)

・矢を射る(1秒のクールダウンタイム)

・着火済みTNTを置く(3回まで)

・指定した種類のスプラッシュポーションを投げる(3回まで)
### 移動系
・敵の方向を向く

・まっすぐ歩く

・指定した方向を向く



## コマンド
**/battle start <MOB名>** :  MOB vs プレーヤーのバトルを開始します。

**/battle start <MOB名1> <MOB名2>** :  MOB1 vs MOB2のバトルを開始します。

**/battle stop** : バトルを強制終了します。
