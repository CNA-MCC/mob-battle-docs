🧟 ゾンビAI 開発リファレンス

オープンキャンパス Mob AI バトル企画 — onTick() の中身を書くための関数一覧

概要 基本の仕組み 言葉のミニ辞典 if文とブロック・return 演算子の使い方 コマンド アクション系の関数 移動系の関数 その他の関数 呼んではいけない関数 サンプルコード

🧟概要

このゲームでは、チームごとにゾンビの行動プログラム(AI)を書いて、ゾンビ同士をバトルさせます。 すでに用意されているクラスと onTick() という場所(あとで説明します)があるので、 みなさんが書くのは「ゾンビにどう動いてほしいか」を onTick() の中に書くだけです。

ゾンビには、あらかじめこんな行動をさせることができます。

  • 剣で攻撃する / 矢を射る / TNTを投げる / ポーションを投げる
  • 敵の方を向く、まっすぐ歩く、好きな方向を向く
  • 自分や敵の体力・位置・距離・持ち物を調べる
  • 少しの間待つ、チャットにメッセージを送る

これらの行動それぞれについて、下の方で1つずつ説明とサンプルコードを載せています。

⚙️基本の仕組み

  • onTick() は、バトルが始まると1秒間に10回、自動でくり返し呼ばれ続ける場所です。 ここに書いた内容が、そのままゾンビの「考え方」になります。
  • 相手がいない・倒れている・バトルが始まる前は、onTick() の中身は実行されません(気にしなくて大丈夫です)。
  • 体力は名前の上のハート(❤)で自動的に表示されます。特に何もしなくてOKです。
  • 最初からネザライトの防具一式・ポーション3個・TNT3個・矢64本を持った状態で始まります。
  • 「剣で攻撃する」と「矢を射る/TNTを投げる/ポーションを投げる」は、1回のtickにつきどちらか1つだけ効果があります。両方書いても、後に書いた方は無視されます。
  • 「まっすぐ歩く」という関数を呼ぶと、実際に歩き終わるまで数tickかかります。歩き終わったかどうかは「移動中か確認」する関数で調べられます。

📘言葉のミニ辞典

ドキュメント中でよく出てくる言葉を、先にかんたんに説明しておきます。以降は「関数」という呼び方で統一します。

言葉意味
関数プログラムの中で「○○()」という形で書くと、何かをしてくれる操作のこと
戻り値関数を実行した結果として得られる情報のこと(例:距離や体力の数字)。関数によっては何も返さないものもあります
引数(ひきすう)関数の( )の中に渡す追加の情報のこと。例えば moveForward(3) の 3 は「3ブロック分歩く」という指定です
数値・true/false戻り値の種類。数字だったり、「はい/いいえ」(true/false)だったりします

🔀if文とブロック・return

if文(もし〜だったら)

「もし〜だったら、こうする」という条件分岐を書くのが if文 です。ゾンビの行動を切り替えるために一番よく使います。 

if (getDistanceToTarget() < 3) {
    holdSword();
    attack();
}

if のすぐ後ろの( )に条件を書きます。条件が成り立つ(true)時だけ、続く { }(ブロック)の中身が実行されます。 条件が成り立たない(false)時は、{ } の中身はまるごと無視されます。

ブロック { } について

TIPS { } はブロックと呼ばれる「まとまり」の印です。中に何行書いても、条件が成り立った時にすべてまとめて実行されます。 1行だけでも、必ず { と } で囲む書き方に慣れておくとミスが減ります。 
if (getHealth() < 5) {
    setYaw(getYaw() + 180); // 反対を向いて
    moveForward(10);        // 逃げる
}

else / else if(条件が成り立たなかった時)

if の後に else を続けると、「条件が成り立たなかった場合」の行動も書けます。 else if を挟むと、条件を上から順に複数チェックできます。 

if (getDistanceToTarget() < 3) {
    holdSword();
    attack();          // 近ければ剣で攻撃
} else if (!isMoving()) {
    lookAtTarget();
    moveForward(3);     // 遠ければ近づく
} else {
    say("待機中");      // どちらでもなければ
}
TIPS if → else if → else は上から順番にチェックされ、最初に条件が成り立ったブロックだけが実行されます。 どの条件にも当てはまらなかった時の行動は、最後の else { } に書きます(elseには条件を書きません)。

return(そこで処理を終える)

return; を実行すると、その場で onTick() の処理をすぐに終わらせます。 それより下に書いてある行は、その回のtickでは実行されません。「これ以上は何もしなくていい」という時に使います。 

if (isMoving()) {
    return; // ここで処理を終える。この下の行は実行されない
}

lookAtTarget();
moveForward(1);
TIPS { } の中が1行だけの場合は、{ } を省略して1行で書くこともできます。 その代表例が、次の定型文です。 
if (isMoving()) return; // 移動中なら、この先の処理をせずに終える

これは onTick()の一番はじめに書く定番の1行です。移動が終わっていないうちに次の指示を出すと動きが乱れることがあるため、 「移動中なら今回は何もしない」という意味でよく使われます。

➕演算子の使い方

関数の戻り値どうしを比べたり計算したりするために 演算子(えんざんし)という記号をよく使います。難しそうに見えますが、算数の記号とほぼ同じです。

算術演算子(数を計算する)

記号意味
+足す
-引く
*かける
/割る
TIPS 関数の戻り値に対しても、そのまま計算ができます。「今の向きに180度足す」= 反対を向く、という意味になります。 
setYaw(getYaw() + 180); // 今の向きに180度足して、反対方向を向く

比較演算子(2つの値を比べる)

記号意味
< / >より小さい / より大きい
<= / >=以下 / 以上
==等しい
!=等しくない
TIPS if (条件) { ... } の( )の中に比較演算子を使うと、「もし〜だったら」という条件分岐が書けます。 
if (getDistanceToTarget() < 3) { // もし敵との距離が3より小さいなら
    holdSword();
    attack();
}

論理演算子(条件をつなげる)

記号意味
&&かつ(両方の条件を満たす)
||または(どちらかの条件を満たす)
!〜ではない(条件を反転させる)
TIPS 複数の条件を組み合わせたい時に使います。「距離が8より遠い、かつ矢が1本以上残っている」なら弓を使う、という判断ができます。 
if (getDistanceToTarget() > 8 && getRemainingArrowCount() > 0) {
    holdBow();
    use();
}

⌨️コマンド

バトルの開始・終了は、ゲーム内チャットに以下のコマンドを入力して行います。

コマンド説明
/battle start <MOB名>MOB vs プレイヤーのバトルを開始します
/battle start <MOB名1> <MOB名2>MOB1 vs MOB2のバトルを開始します
/battle stopバトルを強制終了します

<MOB名> の部分には、自分のチームが作ったAIクラスの名前を入力します。

⚔️アクション系の関数

攻撃や武器の使用に関する関数です。武器は「持つ」→「使う」の2ステップになっているものが多いです。

剣で攻撃するholdSword() / attack()

holdSword() で剣を持ち、attack() で近くの敵を攻撃します。 効果があるのは、敵との距離が3ブロック以内で、かつ前回の攻撃から1秒以上経っている時だけです(1秒のクールダウンがあります)。 

holdSword();  // 剣を持つ
attack();     // 近くにいたら攻撃する

矢を射るholdBow() / use()

holdBow() で弓を持ち、use() で矢を発射します。 1秒に1回まで、矢の残りは最大64回です(残数は後述の関数で確認できます)。 

holdBow();  // 弓を持つ
use();      // 矢を発射する

着火済みTNTを投げるholdTNT() / use()

holdTNT() でTNTを持ち、use() 前方に投げます。 置いた3秒後に爆発します。使えるのは最大3回です。 

holdTNT();  // TNTを持つ
use();      // 前方に投げる(3秒後に爆発)

指定した種類のスプラッシュポーションを投げるholdPotion(種類) / use()

holdPotion() の引数に、投げたいポーションの種類を指定してから use() で投げます。 投げる方向は自分が向いている方向なので、投げる前に敵の方を向いておくのがおすすめです。 使えるのは最大3回です。範囲攻撃なので、近くにいると自分も効果を受けることがあります。

種類の指定には PotionType.INSTANT_HEAL(回復)や PotionType.INSTANT_DAMAGE(ダメージ)などが使えます。

ゾンビはアンデッド(不死系)のモンスターなので、ポーションの効果が人間と逆になります。 INSTANT_HEAL(回復ポーション)を浴びるとダメージを受け、 逆に INSTANT_DAMAGE(ダメージポーション)を浴びると回復してしまいます。 相手(=敵ゾンビ)を攻撃したい時は INSTANT_HEAL を、自分を回復させたい時は INSTANT_DAMAGE を投げる、と覚えておきましょう。 
lookAtTarget();                    // 敵の方を向く
holdPotion(PotionType.INSTANT_HEAL); // 敵はゾンビなので、回復ポーションが実質ダメージになる
use();                             // 投げる

🏃移動系の関数

敵の方向を向くlookAtTarget()

今戦っている敵がいる方向を向きます。何かを敵に向けて撃つ・投げる前によく使います。

lookAtTarget(); // 敵の方を向く

まっすぐ歩くmoveForward(歩く距離)

今向いている方向に、指定したブロック数だけ歩きます。引数の数字が大きいほど遠くまで歩こうとします (指定できる範囲は-30〜30で、マイナスの数字を指定すると後ろに下がります)。 歩き始めてから実際に到着するまで少し時間がかかるので、歩き終わったかどうかは「移動中か確認」する関数で調べましょう。 

lookAtTarget();
moveForward(3); // 3ブロック分、前に歩く

指定した方向を向くsetYaw(角度)

方角を数字(角度)で指定して、その方向を向きます。今向いている方向の数字を調べる関数(getYaw())と組み合わせて、 「今の反対を向く」といった使い方もできます。 

setYaw(getYaw() + 180); // 今の反対方向を向く(逃げるときなどに便利)
moveForward(10);

🔍その他の関数

自分の向いている方向を取得getYaw()

自分が今向いている方向を、角度の数字として返します。

getYaw();

自分の体力を取得getHealth()

自分の残り体力を数字として返します。体力が減ってきたら逃げる、といった判断に使えます。

if (getHealth() < 5) {
    // 体力が少ないので逃げる、などの処理をここに書く
}

敵の体力を取得getTargetHealth()

敵の残り体力を数字として返します。

if (getTargetHealth() < 5) {
    holdSword();
    attack(); // 敵の体力が少ないので畳みかける
}

敵の位置を取得getTargetLocation()

敵が今いる座標(位置の情報)を返します。

getTargetLocation();

敵との距離を取得getDistanceToTarget()

自分と敵の間の距離を、ブロック数の数字として返します。近づく・離れるの判断で一番よく使う関数です。

if (getDistanceToTarget() < 3) {
    holdSword();
    attack();
}

敵の武器を取得getTargetWeapon()

敵が今どんな武器を持っていそうかを返します。TNTを持っている敵からは離れる、といった作戦に使えます。

if (getTargetWeapon() == Weapon.TNT) {
    moveForward(-5); // TNTを持たれたら下がる
}

ポーション、TNT、矢の残数取得getRemainingPotionCount() / getRemainingTNTCount() / getRemainingArrowCount()

それぞれ、あと何回ポーション・TNT・矢が使えるかを数字で返します。0になったら、その行動は使えません。

if (getRemainingArrowCount() > 0) {
    holdBow();
    use();
}

移動中か確認isMoving()

「まっすぐ歩く」で出した移動がまだ終わっていないかを、true(はい・移動中)/false(いいえ・止まっている)で返します。 onTick()の一番はじめに if (isMoving()) return; と書いて、移動中は何もしないようにするのが定番です。 

if (isMoving()) return; // 歩いている途中なら、この先の処理をしない

一定時間停止sleep(ミリ秒)

指定した時間(ミリ秒。1000で1秒)の間、onTick()の処理を丸ごと止めます。「攻撃したあと少し待ちたい」といった場面で使えます。 100の倍数を指定するのがおすすめです。 

attack();
sleep(1000); // この後1秒間、onTick()の中身は実行されない

チャットを送るsay(メッセージ)

指定した文字をゲーム内のチャットに送ります。今どんな状態か確認したい時など、動作チェックに便利です。

say("体力: " + getHealth());

🚫呼んではいけない関数

以下の関数は、ゲームの仕組み側が必要なタイミングで自動的に呼び出すためのものです。 みなさんが書く onTick() の中から、直接呼び出さないでください。

  • setEntity()
  • getMob()
  • initialize()
  • updateNameTag()
  • startBattle()
  • shouldActivate()
  • shouldStayActive()
  • start() / stop()
  • getKey() / getTypes()

🧩サンプルコード

近づいてTNTを投げて離脱する作戦

onTick() {
    if (isMoving()) return;

    lookAtTarget();
    moveForward(1);

    if (getDistanceToTarget() < 3) {
        holdTNT();
        use();
        setYaw(getYaw() + 180);
        moveForward(10);
    }
}

距離に応じて武器を使い分ける作戦

onTick() {
    lookAtTarget();

    if (getDistanceToTarget() > 8 && getRemainingArrowCount() > 0) {
        holdBow();
        use();
    } else if (getDistanceToTarget() < 3) {
        holdSword();
        attack();
    } else if (!isMoving()) {
        moveForward(3);
    }
}
getDistanceToTarget() や getTargetWeapon() を組み合わせて、相手の武器に応じて逃げる・攻める判断を作るのもおすすめです。
